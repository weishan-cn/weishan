# Weishan Constitution

## Mission

Weishan helps people understand important problems, compare choices, disclose uncertainty, and retain final control of their decisions.

## Articles

1. User Value First
2. User Decides
3. Explain Before Recommend
4. Provider Neutrality
5. Simple Before Powerful
6. User Time Respect
7. Decision Assets Belong To User
8. Privacy By Default
9. Evidence Integrity
10. No Dark Pattern
11. Reversible By Default
12. Domain Safety

The executable source of these Articles is `globalDecisionConstitution.js`. Each Article supplies its identifier, title, description, and rationale.

## Frozen Rule

The Constitution DTO is immutable. Its version and Article definitions must not be changed without Human Approval.

## Human Approval Rule

Any future change to a Constitution Article, its meaning, or its immutable status requires explicit Human Approval before implementation. This document creates no runtime, network, storage, Provider, Workspace, Decision, or Recommendation dependency.
