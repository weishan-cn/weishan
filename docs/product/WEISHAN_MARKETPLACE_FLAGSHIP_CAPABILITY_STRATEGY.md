# Weishan Marketplace Flagship Capability Strategy

Marketplace is a consumer capability store. Its primary question is “What can Weishan help me do?” Implementation/provider names are secondary technical details.

## Flagship order

1. **Video Studio** — 制作短视频
2. **Software Development** — 写代码和修项目; Codex is one possible implementation
3. **Web Automation & Capture** — 自动操作和整理网页; OpenClaw is one possible implementation
4. **Image Studio** — 生成和编辑图片; existing Image Tools proves Runtime V2 compatibility
5. **Office & Documents** — 处理 PDF、表格和演示文稿
6. **Advanced Agent / Deep Work** — 完成复杂长任务; Hermes is one possible implementation

The landing surface orders high-frequency outcomes before technical catalogs. Standard mode shows consumer titles, examples, truthful readiness, trust, size, permissions, local/online requirements, and cost/service dependencies. Advanced mode adds plugin IDs, runtime version, capability IDs, execution mode, and implementation provider.

Popularity is a marketplace presentation signal, not Brain recommendation authority. Sponsored placement or plugin commission cannot influence Brain selection. Missing intent capabilities produce an install recommendation when a verified pack is available or a truthful “planned, not install-ready” recommendation when only a foundation exists.

Video comes first because it is high-frequency, visually legible, relevant to social-media workflows, and demonstrates safe multi-capability composition. Software and web abilities remain accessible through Home, Tools, and task suggestions; Software Factory and Web Capture remain Advanced rather than returning to primary navigation.
