# Weishan Plugin Marketplace V1

The product surface is named **Tools** in Standard mode. It answers what capability can be added, not which registry technology to configure.

Phase 1 has Installed, Add capabilities, details, permissions, trust, download/install sizes, local/online/hybrid dependency, cost/service disclosure, enable/disable, and uninstall retention choice. Advanced mode may show plugin IDs, runtime versions, capability IDs, execution modes, manifests, and diagnostics. Local-developer sideloading is never exposed in Standard mode.

The catalog is local and makes zero startup network requests. It does not advertise fixture entries as downloadable. A future backend needs signed manifests/packages, publisher identity, review status, platform compatibility, version/update metadata, revocation notices, and privacy-safe popularity signals. Revocation can block activation but must not remotely delete user data.

Trust classes are Weishan Official, Verified Publisher, Community, and Local Developer. Updates revalidate signature, publisher, integrity, capabilities, and permissions; permission expansion blocks automatic update. Marketplace placement or commercial relationships never change Brain selection.
