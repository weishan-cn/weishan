# Decision Design System

This is a semantic experience contract, not a visual theme. It orders Question, needed information, options, evidence, risks, tradeoffs, simulation, recommendation, user decision, and user-selected save or exit. Evidence and risks precede recommendations; users can always exit.

Screen Contracts do not create UI. They enforce one primary question, one primary action, at most two secondary actions and three buttons, no default menu, visible save behavior, and no commercial or Provider-priority action.

Progressive disclosure uses Essential, Important, and Detailed layers. Major risks, key limitations, irreversible consequences, and key evidence cannot be hidden in Detailed.
