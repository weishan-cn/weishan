# Weishan Roadmap

## Short-Term Roadmap

- Stabilize local-first email takeover.
- Improve regression tests.
- Strengthen permission-gated workflows.
- Expand provider sandbox and dry-run flows.
- Improve release workflow.
- Improve contributor onboarding.
- Improve security documentation.

## Email Takeover Stabilization

Continue hardening user-authorized email workflows, including risk checks, permission prompts, and clear boundaries around draft generation and sending.

## Tests

Expand regression coverage for desktop flows, local API endpoints, email risk checks, security boundaries, and release checks.

## Provider Sandbox

Continue developing provider sandbox and dry-run flows without bypassing review, user authorization, or safety boundaries.

## Release Workflow

Keep release checks repeatable, documented, and easy for maintainers to run before tagging.

## Contributor Onboarding

Improve documentation for setup, testing, security expectations, and pull request review.

## Security Documentation

Keep the security model current as provider, API, and workflow capabilities evolve.
