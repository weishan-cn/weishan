# Product Gate

The Product Gate is a feature-design review, not a release gate, deployment gate, or runtime permission system. It consumes the full Governance Runtime result and returns `PRODUCT_GATE_PASS`, `PRODUCT_GATE_WARNING`, or `PRODUCT_GATE_REJECTED`.

A proposal must explain the real user problem, steps saved, risk reduced, understanding gained, simpler alternative, and loss without the feature. Engagement, advertising, commissions, Provider conversion, frequency, notifications, and addiction are not user-value evidence.

Allowed quality metrics are task completion, decision clarity, explanation coverage, risk coverage, evidence transparency, user-controlled completion, time saved, and reversibility. Time spent, engagement, conversion, notification opens, scroll depth, and retention manipulation are prohibited.

The Gate rejects frozen or public-contract changes, Decision Core or Constitution mutation, Provider or commercial ranking influence, tracking or profiling, automatic Workspace creation, automatic decisions for users, source declarations presented as facts, cross-domain rule leakage, business execution by Governance, or failed complexity limits. A rejected proposal must be changed and reviewed again; this Gate does not authorize release or implementation.
