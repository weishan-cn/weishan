# Trust and Recommendation Presentation

Trust Presentation labels facts, user input, source declarations, assumptions, analysis basis, limitations, and recommendations without changing Evidence meaning. A source declaration remains unverified; an assumption or analysis basis never becomes a fact; limitations remain visible.

Recommendation Presentation only explains an existing recommendation. It cannot recalculate ranking or let commercial relationships affect summary, reasons, risk, alternatives, or confidence. It requires evidence, risks, tradeoffs, assumptions, limitations, alternatives, and an explicit user decision.
